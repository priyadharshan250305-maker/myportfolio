# Priyadharshin: Portfolio

Plain HTML, CSS and JavaScript. No build step. Open `index.html` in a browser.

## Folder structure
```
portfolio/
  index.html   content (search for [ADD ...] placeholders)
  style.css    design tokens at the top (colours, fonts)
  script.js    menu, scroll reveal, contact form
  assets/images/profile.jpg   your photo
  assets/icons/               put logos/icons here
```
